## Before you repost

1. Open the canonical URL in a private window. The article should load, with the headline "What to automate first in a Caribbean business".
2. View the page source (right click, View Page Source) and search for a sentence from the article, for example "Repetition beats size". If the text is in the source, Medium's importer can read it. Medium's importer does not run JavaScript, so a page that only fills in after it loads comes through blank.
3. Optional but worth it: in Google Search Console, paste the URL into URL Inspection and press Request indexing, so Google has seen our copy before the Medium one exists.

## Medium

Medium's "Import a story" tool copies the article into a draft, backdates it to the original date and adds a canonical link to our page by itself. You do not set the canonical link by hand. (Source: Medium Help Center, [Importing a post to Medium](https://help.medium.com/hc/en-us/articles/214550207).)

### Steps

1. Sign in to Medium on the account that should carry Forged One's articles.
2. Click your profile picture, top right, and choose **Stories**.
3. Click **Import a story**, top right of the Stories page.
4. Paste `https://forgedone.xyz/articles/what-to-automate-first` and click **Import**.
5. Click **See your story**. It opens as a draft. Nothing is public yet.
6. Go through the formatting check below and fix anything that came in wrong.
7. Click **Publish**. In the publish box, add the five tags below, then publish.
8. After it is live, open the story's settings, then **Advanced settings**, and confirm the canonical link shows the forgedone.xyz address. If it is empty, use **Customize canonical link**, paste the canonical URL above, and save. (Source: Medium Help Center, [Set a canonical link](https://help.medium.com/hc/en-us/articles/360033930293).)

### Formatting check

The importer reads the whole page, so it can pick up too much or too little. Check, in this order:

- **Title.** It should read "What to automate first in a Caribbean business". If it came in as "What to Automate First in a Caribbean Business | Forged One", delete the " | Forged One" part.
- **Site furniture.** Delete anything that is not the article: the breadcrumb, the date and reading time line, the "Start the brief" and "Book a call" buttons, the related pages at the end, and any footer text.
- **Opening.** The first paragraph should be the one that starts "Automate the job your team repeats most".
- **Headings.** There are six. Each should be a Medium heading, not bold body text: Repetition beats size; Four jobs worth looking at first; Hours back against how buildable it is; What not to automate; Start with one job and one number; Let the brief do the sorting.
- **Lists.** There are three: the four quoted lines in the first section, the four buildability questions, and the three "leave alone" items. Check each is still bulleted, not run together into one paragraph.
- **Links.** Hover every link. There are six, and each must go to forgedone.xyz or brief.forgedone.xyz, never to a medium.com address. The page already writes them as full addresses, so they should come through as they are. Fix any that do not, using the full address, for example `https://forgedone.xyz/services/ai-agents`.
- **The close.** The last paragraph ends "Nobody will miss doing it." If the importer dropped the link to the Build Brief in the paragraph before it, put it back: `https://brief.forgedone.xyz/`.
- **The "originally published" line.** If Medium added a line at the end saying where the story was first published, keep it.

### If the import fails

If Import shows a blank page or an error, the importer could not read the article out of the page. Check step 2 under "Before you repost" again. If the text is in the source and it still fails, copy the article into a new Medium story by hand, set the canonical link as in step 8, and publish. Medium's help centre covers this in [Trouble importing content using the import tool](https://help.medium.com/hc/en-us/articles/360033931713).

## Checklist for every future article

The same order every time. Our page is the original, so it always goes first.

1. **Publish on the site.** The article file is merged and deployed.
2. **Wait until it is live.** Open the address in a private window. Check the text is in the page source, not only on screen. Check it is listed on /articles. Optionally, request indexing in Google Search Console.
3. **Import to Medium.** Profile picture, Stories, Import a story, paste the address, Import, See your story. Run the formatting check: title without " | Forged One", site furniture removed, headings and lists intact, every link going to forgedone.xyz. Add five tags. Publish. Confirm the canonical link in Advanced settings.
4. **Post to LinkedIn.** From the company page. A first line that would stop your own scroll, 120 to 200 words, three to five hashtags led by #ForgedOne, and the article's address as the last line. Wait for the preview card before posting.
5. **Record the links** in a "Where it went" list like the one above.
6. **If the article changes later,** change it on the site first and set its `updated` date. Then edit the Medium copy to match by hand; the importer will not do it again for you.
